# AGENT.md — GeoTrack

## AI-Assisted Development Disclosure

This document provides a brief and transparent overview of AI assistance used during the development of GeoTrack.

---

## 🇮🇩 Bahasa Indonesia

### 1. Penggunaan AI

AI digunakan sebagai alat bantu teknis selama pengembangan GeoTrack, terutama untuk eksplorasi pendekatan implementasi, referensi kode, analisis masalah, debugging, dan penyusunan dokumentasi.

Penggunaan AI mencakup dukungan pada pengembangan frontend React TypeScript, backend Go, integrasi SQLite, serta visualisasi peta menggunakan Leaflet.

### 2. Implementasi dan Verifikasi

Pengembangan dilakukan secara bertahap dengan memeriksa hasil implementasi melalui pengujian langsung.

Proses verifikasi meliputi:

- Pengujian fitur CRUD melalui aplikasi dan Swagger UI.
- Pemeriksaan penyimpanan dan perubahan data menggunakan SQLite.
- Pengujian validasi input frontend dan backend.
- Pengujian visualisasi peta, pencarian, filter, dan pagination.
- Verifikasi build frontend menggunakan `npm run build`.

### 3. Tanggung Jawab Pengembangan

AI digunakan sebagai alat pendukung, bukan sebagai pengganti pengujian dan evaluasi teknis.

Saran maupun kode yang diperoleh dengan bantuan AI diperiksa melalui proses implementasi, debugging, dan pengujian fungsional.

Pengembang bertanggung jawab atas hasil akhir proyek dan dokumentasi yang diserahkan.

## 🇬🇧 English

### 1. AI Usage

AI was used as a technical assistant during GeoTrack development, primarily for exploring implementation approaches, code references, problem analysis, debugging, and documentation.

AI assistance supported the React TypeScript frontend, Go backend, SQLite integration, and Leaflet-based map visualization.

### 2. Implementation and Verification

Development was carried out incrementally, with implementation results evaluated through direct application testing.

Verification included:

- CRUD testing through the application and Swagger UI.
- SQLite data persistence and update verification.
- Frontend and backend input validation testing.
- Map visualization, search, filtering, and pagination testing.
- Frontend build verification using `npm run build`.

### 3. Development Responsibility

AI was used as a supporting tool rather than a replacement for technical evaluation and testing.

AI-assisted suggestions and code were reviewed through implementation, debugging, and functional testing.

The developer remains responsible for the final project and submitted documentation.
